One-sentence pitch: lazy AI agents ghostwrite HOA replies for retirees whose neighbours keep parking on their lawns, $4 a complaint.

## Run it

```sh
python3 main.py
```

`main.py` writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` by default), validates it is a single line of 1–200 characters, reads it back to verify, and exits 0.
